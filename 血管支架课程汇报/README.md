# 血管支架课程汇报

本项目使用用户提供的LaTeX学术汇报模板，直接以XeLaTeX编写并输出PDF。画布为960 × 540 PDF点，保留微软雅黑粗体、藏青页眉、华中科技大学校徽及底部结论区。

封面的“医工交叉研究前沿进展”采用正文页相同的顶部标题样式，不加“课程”前缀。封面不显示导师栏，下方保留六位汇报成员及时间。

大纲页仅列“研究背景与意义、研究现状、创新思路、结论与展望”四项，取消导语、下级说明及底部结论栏。条目复用参考模板目录的文本框位置与宽度；字号与各页标题一致，均为32pt，行距按后续要求由64pt增至80pt。section in toc样式继承frametitle，01—04编号使用相同字号，保留红色。

按最新要求，除标题与参考文献外，可编辑文字统一调大2pt：正文20pt、要点22pt、详细说明18pt、图注16pt、提示14pt、底部结论22pt、封面成员信息22pt。封面主标题与页标题仍为32pt，参考文献仍为9pt；已发表图件中的原始标注予以保留。字号通过主题中的语义样式统一设置。普通正文、说明及表格中的连续文字按文本框宽度自动换行，仅在封面署名、公式、独立列表或文献分组等有具体排版需要的地方保留手动分行。

## 编译

需要XeLaTeX、Beamer、xeCJK、fontspec、TikZ及Microsoft YaHei字体。当前环境使用TeX Live 2025。

在本项目目录执行三次：

~~~powershell
xelatex '-interaction=nonstopmode' '-halt-on-error' '-file-line-error' '-output-directory=.build' main.tex
~~~

重复编译用于更新页数与TikZ记忆坐标。验证.build/main.pdf后，复制为项目根目录的最终PDF。
